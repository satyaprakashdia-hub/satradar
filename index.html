Auto-Open When Bike / Car Starts

Because iOS and Android browsers don't allow a website to launch itself from the background, connect this app to your phone's built-in Bluetooth automation so it opens automatically whenever your bike or car connects:

iOS / iPhone Apple Shortcuts Automation
  1. Open the Shortcuts app → tap Automation → tap +.
  2. Choose Bluetooth → select your Bike / Helmet / Car → pick Is Connected → Run Immediately.
  3. Add action Open URLs (or Open App if added to Home Screen) pointing to SatRadar Pro.
  4. When you start your bike, your iPhone triggers SatRadar Pro automatically and arms live GPS.
Android Modes & Routines / MacroDroid
  1. In Chrome, tap ⋮ → Add to Home screen to install SatRadar Pro like a native app.
  2. Open Settings → Modes & Routines (Samsung) or MacroDroid (any Android).
  3. Set Trigger: Bluetooth Device Connected → [Your Bike / Car].
  4. Set Action: Open App → SatRadar Pro (and optionally set Media Volume to 85% for helmet voice alerts).
